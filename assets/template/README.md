# World Template

Copy this directory to `assets/<world>/` to start a local world workspace.

A world groups assets that share a visual language. Keep its style material in `style/`, resources reused within the world in `shared/`, one loose folder per model in `models/`, and unit and ability icons in `icons/`.

Git tracks this template as the sole exception beneath `assets/`; copied world workspaces remain ignored. The README files explain placement but do not require you to maintain written records.

See [the workspace contract](../../docs/workspace.md) for the ownership and promotion rules.
